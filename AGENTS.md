# Project instructions

- Always provide suggested commit messages in English.

## Stack

- Local WordPress in Docker (`docker-compose.yml`): `wordpress` (Apache + PHP), `mysql-db` (MySQL 8.4), `phpmyadmin`, `wp-cli`. Routed by the shared Traefik on the external `web` network.
- `PROJECT_NAME` in `.env` drives container names, DB credentials and hostnames:
  - site: `http://<PROJECT_NAME>.localhost`
  - phpMyAdmin: `http://pma.<PROJECT_NAME>.localhost`
- `./wordpress` is mounted as `/var/www/html`. WordPress core lives there but is not ours — do not edit it.
- PHP limits: `docker/php/uploads-custom.ini`.

## What is tracked

- Root `.gitignore` is generated by `scripts/init-wordpress.sh` on every container start — edit the heredoc in the script, not the generated file.
- Tracked: `wordpress/wp-content/plugins/**` and the project theme `wordpress/wp-content/themes/<PROJECT_NAME>/**`.
- Not tracked: core, uploads, other themes, `docker-compose.yml`, `scripts/`, `.env`.
- Do not modify third-party plugins (ACF Pro, WooCommerce, Yoast, CF7, …). Put customisations in the theme or in a dedicated custom plugin.

## Theme (`wordpress/wp-content/themes/<PROJECT_NAME>/`)

Block (FSE) starter: `theme.json`, `templates/*.html`, `parts/*.html`, SCSS + Webpack, PSR-4 autoloader in `functions.php` (`app/` => namespace `NowaTemplatka\`, no Composer needed at runtime). Pages are edited visually in the Site Editor; custom blocks are ACF blocks with `InnerBlocks` (generator: `npm run create-block -- <slug> "<Title>" [--inner]`).

- `assets/tokens.json` — single source of design tokens (colours, fonts, font sizes, spacing, layout, breakpoints). `npm run theme-json` generates `theme.json` and `assets/scss/base/_tokens.scss` from it — never edit those two by hand.
- `assets/scss/` — `main.scss` (front) and `editor.scss` (editor iframe), both built into `public/`. `public/` is webpack output — never edit it by hand.
- `app/Core/` — `Theme` (setup), `Assets` (loads `public/main.css`, editor styles).
- Templates and parts are plain block markup (no PHP runs in `.html` files).
- Blocks live in `views/blocks/<slug>/` (`block.json`, `render.php`, `_<slug>.scss`, `<slug>.js`, `group_<slug>.json`). `app/Blocks/Registry.php` registers them and routes ACF Local JSON there. Block JS is lazy-loaded when `.wp-block-acf-<slug>` is in the DOM. Requires ACF Pro 6.2+ (not bundled). Shared options (background, width, space above/below) live in one ACF group, `views/blocks/section/group_section_settings.json`, whose location lists every block that uses it; markup helpers are in `app/Blocks/Render.php` (`wrapper()`, `container()`, `head()`, `buttons()`, `image()`) and shared styles in `assets/scss/base/_sections.scss`.
- Do not add a `postinstall` script to `package.json`.

## Commands

Theme build (run on the host, in the theme directory, Node from `.nvmrc`):

```bash
npm run dev      # watch (regenerates theme.json first)
npm run build    # production build; run after changing SCSS/JS
```

WP-CLI (from the project root):

```bash
docker compose run --rm wp-cli wp <command>
docker compose exec mysql-db mysql -u<PROJECT_NAME>_user -p<PROJECT_NAME>_password <PROJECT_NAME>_db
```

## Rules

- Content and admin UI are in Polish; code, comments and commit messages in English.
- Do not run destructive DB commands (`wp db reset`, `wp search-replace` without `--dry-run`, drops, imports) without asking.
- Verify changes in the browser at `http://<PROJECT_NAME>.localhost` after a build.
